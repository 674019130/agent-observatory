# Impeccable Design Context

## Design Context

### Users
Agent Observatory is for technical macOS users who actively use Claude Code, Codex, local skills, MCP servers, and long-term memory files. They are inspecting privacy-sensitive local files and need to understand what an agent can see, why it can see it, and what action is safe to take next.

### Brand Personality
Calm, precise, inspectable. The app should feel like a native Apple utility for serious agent work: quiet enough for repeated daily use, but polished enough that important context flows feel trustworthy and deliberate.

### Aesthetic Direction
Use a native macOS information-work style with gallery-like moments for high-level overview. Favor system materials, semantic colors, compact density, crisp typography, and restrained motion. Avoid marketing pages, heavy decorative gradients, nested cards, oversized hero typography, or generic dark technical dashboards.

### Design Principles
- Show provenance before action: every recommendation or preview should keep source paths and load routes close to the decision.
- Make hidden complexity legible: expose memory, skills, MCP, plugins, and prompt assembly as understandable layers rather than raw file dumps.
- Keep expert workflows fast: default to dense, scannable layouts with progressive disclosure for detail.
- Treat destructive or cross-agent operations as inspectable: preview, destination, collision state, and copy result should be visible before the user acts.
- Preserve native macOS behavior: pointer affordances, keyboard access, split-view navigation, Finder reveal, adaptive colors, and reduced-motion friendliness matter more than decorative novelty.
